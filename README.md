# gh-nixpkgs-review

a _very_ small `gh` extension to provide a more convenient way to use **nixpkgs-review-gha**

> [!note]
> this extension was made mainly for my usecase and is thus quite minimal. \
> if you want anything to be added, feel free to open a pr or issue

## usage

```shell
gh nixpkgs-review <pr number>
```
